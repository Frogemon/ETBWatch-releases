# ETBWatch

A free Windows app that watches Pokémon ETB and TCG product pages and alerts
you the moment one can be bought online. It never adds to cart or checks out
for you.

**[Download the latest version for Windows](https://github.com/Frogemon/ETBWatch-releases/releases/latest/download/ETBWatch.exe)**

Website: https://etbwatch.onrender.com

- Windows 10 or 11, 64-bit
- Single file, nothing to install
- Your tracked products and settings stay on your PC (`%APPDATA%\ETBWatch`)

To update, download the newest version and replace the old file.

This repository only hosts the downloads. Found a bug or have an idea? Open an
issue here.
